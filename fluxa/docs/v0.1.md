# Fluxa 模擬器 v0.1

日期：2026-10-29 之前（初版）

## 定位

Fluxa 語言（HLS 硬體設計語言）的行為模擬器：Kahn 程序網路（KPN）直譯器，
類比 `iverilog` / `vvp` 之於 Verilog。純 Rust、零外部依賴。

- 每個 `task` 一條 OS 執行緒；通道是有界 FIFO（`depth`），滿了 `send` 阻塞、空了 `recv` 阻塞。
- 輸出 token 序列與排程、FIFO 深度無關（KPN 確定性，規格 §3.10 性質 5）。
- 死結偵測：所有存活任務都在等待時，逐一報告卡在哪條通道。
- 通道端點（`Tx`/`Rx`）是線性資源：`spawn` 轉移所有權，之後再用報錯；
  任務結束時自動關閉持有的 `Tx`（end-of-stream），`for x in rx` 自然結束。
- 位寬安全：以精確 120 位元整數運算，在每個有型別的落點檢查範圍（E0301）；
  窄化必須顯式（`as`、`.to::<T>`、`.sat::<T>()`、`.wrap::<T>()`）。
- `@reg`：迭代內讀舊值、迭代結束提交（硬體移位暫存器語意）。
- `fixed<I,F>` 精確定點算術：加法對齊小數位、乘法小數位相加。

## 語言子集

`const`、`fn` / `comb fn` / `comptime fn` / `task`（含 const 泛型）、`test`、
`let` / `carry` / 賦值、`for`（`pipeline` / `unroll` / `serial` 屬性）、
`if` / `match` / `return`、`spawn` / `parallel`、`assert`、lambda、
位元切片 `x[hi:lo]`、陣列切片 `a[lo..hi]`、定寬字面量 `8'hFF`。

`iface`、`schedule`、`use`、`type` 解析後略過；`stage` 層與 `;;` 明確報錯（週期精確屬另一個模擬器）。
靜態檢查（II 可達性 E0412、bank 衝突 E0401、SDF 速率平衡 E0501）不在此版範圍。

## CLI（單檔）

```
cargo build --release
./target/release/fluxa <file.fx> [options]
```

- 本版只接受**一個** `.fx` 檔（多檔合併是 v0.2 才加入）。
- 選項：`--test NAME`（可重複）、`--list`、`--stats`、`--trace`、`-h`。
- 結束碼：0 = 全部通過、1 = 測試失敗、2 = 載入／語法錯誤。
- 錯誤訊息格式為 `{檔名}:{行號}: …`，行號就是原始檔行號。

## 程式庫介面

- `fluxa::load(file, src) -> Arc<Program>`：解析 + 編譯期常數求值。
- `fluxa::run_test(prog, test, opts)`：每個 `test` 建立獨立模擬世界執行。

## 範例與測試

- `examples/`：`basics`、`fir`、`mac`、`gemm`、`fanout`，
  以及四個預期失敗的 `err_*.fx`（由 `tests/examples.rs` 斷言錯誤訊息子字串）。
- `cargo test --release` 為回歸測試，含 100 次重複的死結誤判檢查。
- 無 CI、無 lint / formatter 設定。

## 程式結構

```
src/lexer.rs    詞法分析          src/runtime.rs  排程、通道、死結偵測
src/parser.rs   語法分析（規格 §2） src/interp.rs   樹走訪直譯器
src/ast.rs      語法樹            src/value.rs    值、型別、定點數與範圍檢查
src/lib.rs      load / run_test   src/main.rs     命令列
```
