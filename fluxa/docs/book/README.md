# Fluxa 程式設計：用 Kahn 通道寫硬體

## 從行為模擬、位寬推導、靜態檢查到 FPGA 合成，以及 AI 時代的硬體開發

如果你會寫程式，就已經具備理解硬體設計最重要的原料。本書帶你從「一段程式如何變成一組真正工作的電路」出發：先用 Fluxa 的範圍型別建立位寬安全，再用 task 與有界通道把演算法組成 Kahn 程序網路，接著以行為模擬作為正確性 oracle，以靜態檢查提前發現窄化、溢位、通道守恆與資源問題，最後一路走到 FSM、資料路徑、FPGA／ASIC 與閘級等價驗證。

本書以 Fluxa 語言規格 v1.0（2026-11-21）與 `rueda 0.7.0` 為基準；書中會區分「目前已實作」與「保留規劃」，不把尚未實作的功能寫成現成能力。
