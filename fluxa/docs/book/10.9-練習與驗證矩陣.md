# 10.9 練習與驗證矩陣

## 10.9.1 三層執行 FIR

對第 7、8 章的 FIR，依次執行：

```sh
reda sim fluxa/examples/fir4.fx
reda emu --top Fir fluxa/examples/fir4.fx
reda synth --top Fir fluxa/examples/fir4.fx
reda gatesim opt --top Fir fluxa/examples/fir4.fx
```

保存每一層的輸出，並回答：

- 三層的測試名稱與通過狀態是否一致？
- 輸出 token 序列是否一致？
- 若不一致，第一個差異發生在哪個測試？

## 10.9.2 故意改錯一個策略

把 FIR 的某一輪捨入或飽和策略改錯（例如把 `sat` 改成 `wrap`），觀察哪一層先抓到問題：

- 行為模擬是否立即失敗？
- 編譯後模擬是否也失敗？
- 閘級模擬的輸出與行為層差在哪裡？

這個練習的目的不是製造 bug，而是理解每一層能看到什麼、看不到什麼。

## 10.9.3 建立一張驗證矩陣

為你的設計建立類似的表格：

| 案例 | sim | emu | gatesim opt | 目標後端 | 比較欄位 |
| --- | --- | --- | --- | --- | --- |
| 正常 |  |  |  |  | 斷言、token |
| 邊界 |  |  |  |  | 斷言、token |
| 關閉 |  |  |  |  | 結束狀態 |
| 錯誤輸入 |  |  |  |  | 錯誤碼 |

空白欄位不是「還沒做」，而是「尚未有證據」。把它們補滿，就是本章的實作成果。
