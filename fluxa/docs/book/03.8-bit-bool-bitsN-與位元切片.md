# 3.8 `bit`、`bool`、`bits<N>` 與位元切片

整數的範圍語意並不適合所有硬體資料。Fluxa 因此另提供：

| 型別 | 意義 |
|---|---|
| `bit` | 單一位元，不帶整數算術語意。 |
| `bool` | 布林值，供條件判斷與布林運算使用。 |
| `bits<N>` | 固定  $N$  位元的位元向量，不帶整數算術語意。 |

`u8` 與 `bits<8>` 在物理上都占 8 位元，但語意不同：

- `u8` 是有明確數值範圍的整數，可以做加、減、乘與比較。
- `bits<8>` 是一段位元資料，不因為寬度相同就自動具有整數值。

`bool` 與 `bit` 也不應混用。前者描述真假條件，後者描述硬體中的一條位元線，布林運算的結果是 `bool`，位元運算的結果則仍是位元值或位元向量。

### 位元切片

```fluxa
let word: u8 = 0xAB;
let high = word[7:4];   // 4 位元，值為 0xA
let low  = word[3:0];   // 4 位元，值為 0xB
let bit0 = word[0];     // 單一位元
```

`x[hi:lo]` 的兩端都包含，因此切片寬度是：



$$
hi-lo+1
$$



切片索引越界會由模擬器與 `reda check` 診斷。`reda check` 可由索引的推導範圍判斷，例如 `u4` 索引 `0..=15` 不可能安全存取只有 6 個元素的陣列。

切片只保留指定的那些位元。Fluxa v1.0 將單一切片視為該寬度的非負值，切片本身也不會保留來源最高位元所代表的符號。若要採用特定的有號／無號解讀，應先確認端點規則，再寫出明確轉換。
