# 4.14 章末產物：可驗證的 FIR 任務網路

完成本章後，你應能交付一張真正的 FIR 任務網路圖，而不是只有一條呼叫鏈。最低要求如下：

```text
來源／測試
  │ i8 sample stream
  ▼
Fir4
  │ i8 result stream
  ▼
Observe／下游
  ├── i8 result stream
  └── u32 summary
```

這張圖旁邊必須附上：

- 每條通道的元素型別與方向；
- 每條通道的深度；
- token 的順序與數量關係；
- 每一個端點的 owner；
- 每一條通道的關閉責任；
- 至少一個正常案例、一個邊界案例與一個刻意失敗案例；
- 正常與邊界案例的斷言證據；
- 失敗案例的診斷與根因。

如果這張圖可以在不改變外部契約的情況下換掉 FIR、加入預處理器或更換下游，它就是可組合的；如果換掉任一元件就要重寫所有測試與端點約定，它仍然只是把幾段程式放在一起。
