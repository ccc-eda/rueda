# 2.3 值、綁定與控制流：先把行為寫對

### `let`、`let mut` 與落點

Fluxa 的變數有兩種主要宣告形式：

```fluxa
let scale: u8 = 2;       // 不可變，型別明確
let mut total: u8 = 0;   // 可變，型別明確
```

若省略型別，Fluxa 會從初始值推導：

```fluxa
let count = 3;            // 推導為 int<3..=3> 的值域
let samples = [1, 2, 3];  // 推導為陣列
```

但在硬體設計中，型別明確的 `let` 通常更好，因為「這個值將落在哪個硬體寬度上」是契約的一部分。

賦值支援：

```fluxa
total += 1;
total -= 1;
total *= 2;
count = count & 0x0F;
```

不可變變數不能重新賦值；沒有宣告 `mut` 的變數也不能修改。

### `if`、`else` 與 `match`

```fluxa
fn classify(x: u8) -> u2 {
    if x == 0 {
        0
    } else if x < 16 {
        1
    } else {
        2
    }
}
```

`if` 是運算式，可以放在 `let` 右邊或作為函式的最後一個運算式。`match` 適合把離散情況寫成清楚的硬體決策：

```fluxa
fn opcode_class(op: u4) -> u2 {
    match op {
        0 => 0,
        1..=3 => 1,
        4..=7 => 2,
        _ => 3,
    }
}
```

要注意 Fluxa 的兩種範圍語意：

- `a..b` 是右開範圍，包含 `a`、不包含 `b`。
- `a..=b` 是右閉範圍，兩端都包含。

`match` 還支援 tuple 模式：

```fluxa
fn classify_pair(a: u4, b: u4) -> bool {
    match (a, b) {
        (0, 0) => true,
        _ => false,
    }
}
```

`u2` 剛好能容納 `0..=2`。本章不提前講完整值域推導；這裡只提醒：回傳型別不是裝飾，而是回傳落點。

### tuple、陣列、索引與切片

Tuple 可以把多個有不同型別的值綁在一起：

```fluxa
let sample = (7, -3);
let sum = sample.0 + sample.1;
```

陣列長度與元素型別都固定：

```fluxa
let coeffs: [i8; 4] = [1, 2, 3, 4];
let first = coeffs[0];
let middle = coeffs[1..3];
```

固定長度是重要的硬體資訊：它可以對應到常數接線、暫存器陣列或記憶體的形狀。

### 迴圈

Fluxa 有三種迭代來源：

```fluxa
for i in 0..4 { /* i = 0, 1, 2, 3 */ }
for v in samples { /* 陣列元素 */ }
for v in input { /* channel token，直到關閉 */ }
```

`0..4` 不含 4；`0..=3` 才包含 3。

在合成語意中，迴圈還可以帶排程屬性：

```fluxa
unroll for i in 0..4 {
    /* 四份邏輯同時存在 */
}

serial for i in 0..4 {
    /* 四輪循序執行 */
}
```

`pipeline(ii = 1)` 表示每拍啟動一次迭代，是吞吐量要求；第八章會深入它與延遲、面積的關係。本章只要求辨認語法，不把排程細節提前塞進語法導覽。

### Lambda 與陣列方法

Lambda 目前主要用在支援它的內建操作：

```fluxa
let doubled = [1, 2, 3].map(|x| x * 2);
let endpoints = array(4, |_| chan::<u8>(depth = 2));
```

`array(N, |i| ...)` 會依序建立 N 個元素。這在建立固定形狀的 task 網路時很有用。例如脈動矩陣的 16 個 processing element，不需要手寫 16 次 `chan` 與 `spawn`。

但目前 Fluxa v1.0 仍不支援把一般函式或 task 當成值傳給另一個函式。例如 `map(square)` 還不能作為通用平行樣式使用；內建的 lambda 版本則可以。

### `return`

`fn` 與 `task` 都可以用 `return` 提前離開：

```fluxa
fn first_negative(xs: [i8; 4]) -> i8 {
    for x in xs {
        if x < 0 {
            return x;
        }
    }
    0
}
```

`return` 的值也會接受型別檢查。把它看成「離開目前函式或 task」即可。
